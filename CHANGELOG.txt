SUNDAY SAUCERS LINEUP BOARD - CHANGELOG
=======================================
Live app:  https://nichollshd.github.io/saucers-lineup/
Repo:      https://github.com/NichollsHD/saucers-lineup

Newest changes at the top. Each entry: version, date, what changed.
When the app itself changes, also bump CACHE in sw.js (saucers-v9 -> v10...)

Note: "Publish lineup: ..." commits in the repo history are weekly lineups
published from the app, not code changes. They aren't listed here.


---------------------------------------------------------------------
v1.7  -  2026-10-20   (sw.js cache: saucers-v9)
---------------------------------------------------------------------
ADDED
- Game picker on the Publish screen: Game 1, Game 2, Other, or
  Don't log (practice / test publishes that skip the log).
- Game date box (defaults to today; set it to the game day when you
  publish ahead of time).
- Game log: every publish also saves a record to games.json in the
  repo: date, game number, game note, time, field, and the batting
  order with each player's position (or bench). Publishing the same
  date + game again replaces the earlier record instead of adding a
  duplicate. Game 1 and Game 2 are separate records, so changes
  between games are tracked.
- Game log viewer (Publish screen > Game log): per-player totals
  (games in the lineup, games on the field, games on the bench, and
  how many times at each position) plus the list of games.
- Team view shows "Game 1 of 2" / "Game 2 of 2" when a game is picked.
  The WhatsApp message title says "Game 1" or "Game 2" too.
- If the game log can't be saved, the lineup still publishes and the
  screen says so. Publish again to retry.
NOTES
- The log is public in the repo, like the lineup, but it uses first
  names / nicknames only (Tova, Chez, Anthony G.), never full names.
- The published team lineup still shows full names. (Open question.)
- Innings are not tracked yet, only who is in the lineup and where.
  Mid-game substitutions would need a sub button (V3 idea).

v1.6  -  2026-10-19   (sw.js cache: saucers-v8)
---------------------------------------------------------------------
ADDED
- Field list with map links. 17 fields are preloaded: Berry Homes,
  Willowbrook Fields 1-5, Field of Dreams, Bloomingdale Park, South
  Beach 1-8, Walker Park. Each has a name, nicknames (like WB 2 or
  SB 7) and a Google Maps link.
- Field box suggestions on the Publish screen. Type part of a name or
  a nickname and matching fields appear to tap. "Willowbrook" shows
  all five Willowbrook fields to pick from. The box is still free
  text, so a field that isn't in the list shows as plain text.
- Team view: when the field matches, the Field tile becomes a tappable
  link ("Tap for map") that opens Google Maps.
- WhatsApp message: adds a "Map:" line with the link under the field.
- Manage fields (Publish screen): edit names, nicknames and links,
  add or remove fields, or restore the original list. Saved on the
  phone and included in Back up roster / Restore roster.
- Safety: only Google Maps and Apple Maps links are accepted; anything
  else is ignored.

v1.2  -  2026-10-18   (sw.js cache: saucers-v3)
---------------------------------------------------------------------
ADDED
- "Who's in" weekly check-off: every player on one screen, tap to mark
  someone out. The button shows how many are in, e.g. "Who's in (13)".
- "Everyone in" / "Everyone out" buttons to reset for the next week,
  with Undo.
- Batting order size switch: "Top 12 bat" (default) or "Everyone bats".
- Subs: with Top 12, anyone past the 12th batter is listed under a
  "Subs" heading with no number, on the board, the team view, and the
  WhatsApp message ("Subs: ..." line).
- Warning on the board if a sub is placed on the field ("drag him into
  the top 12").
- "Fill open spots" now prefers batters over subs.
CHANGED
- The team view and WhatsApp message only show players who are in this
  week. The "Out today" list is no longer published, so names of
  players who are out never leave your phone.

v1.1  -  2026-10-18   (sw.js cache: saucers-v2)
---------------------------------------------------------------------
ADDED
- One permanent team link (nichollshd.github.io/saucers-lineup/) that
  always shows the latest lineup. Replaces the long share links that
  got cut off in WhatsApp ("Link didn't load").
- Publish to team: the board saves the lineup to lineup.json in the
  repo; the team view loads it.
- Near-live updates: the team view checks for changes every minute and
  whenever the app is reopened, and shows "Lineup updated".
- Manager-only editing: the board requires a manager sign-in (a GitHub
  fine-grained key with Contents read/write on this repo only).
  Everyone else gets a read-only view. "Sign out of manager" button.
- Status messages for offline, no lineup posted yet, and can't reach
  the lineup.
CHANGED
- WhatsApp message ends with "Field view: <team link>" instead of a
  long encoded link.
- Old long links still open (read-only) and point to the latest lineup.
- Service worker never caches lineup.json, so the lineup is always fresh.
- README: Pages setup, install steps, manager key setup, publishing,
  updating.

---------------------------------------------------------------------
- Magnetic lineup board: field diagram, bench tray, and batting order.
- Drag and drop players onto positions, the bench, or batting spots;
  tap a player to edit, or tap an open spot to pick who plays it.
- Player roster with positions each player can play; out-of-position
  warnings (orange magnet); "Can play it" suggestions for open spots.
- 3 or 4 outfielders (LF / LCF / RCF / RF, or LF / CF / RF).
- 12-man batting order: two DH spots stacked on the field, both
  labeled "DH".
- Add / remove players, nicknames on magnets, "playing today" switch.
- Fill open spots, Clear field (with Undo), Start over.
- Publish sheet: game note, ready-made WhatsApp message, Share / Copy.
- Full team roster (19 players) loaded with positions and nicknames.
- Light and dark mode.

PLANNED
---------------------------------------------------------------------
V2
- Player stats (built on games.json, started in v1.7): how to upload them, how they're shown, toggle on/off.
- Player profiles (if we get far enough).
V2 / V3
- Live game feed: a second "scorekeeper" login that can update the
  score, inning, outs, and major events (quick dropdowns) but can't
  change the lineup. Likely its own small repo/key so the scorekeeper
  can't touch lineup.json.
V4
- League edition: scale the app beyond one team, for the league
  commissioner and a place to keep standings for our division. Many
  teams, schedules, scores and standings, with each team managing its
  own lineup. To be worked out when we get there.
V2 / V3: Scorekeeper and live Gameday (design agreed 2026-10-24)
- Scorekeeper view: 7-inning line score (Away always on top, R and H),
  inning, outs (3 dots), and a diamond where tapping a base moves,
  scores or removes a runner. Saucers logo on home plate (need file).
- Saucers at bat: scorekeeper picks the leadoff hitter each inning,
  then taps the result: Walk, 1B, 2B, 3B, HR, Fly / Line / Ground out,
  Strikeout. It moves to the next batter and tracks AB, H, R, RBI,
  BB, K. Suggested extras: Sac fly, Fielder's choice, Error.
- Opponent at bat: same result buttons with no names, plus +1 Run and
  +1 Out. Third out flips the half-inning and fills in a 0.
- "We are Home / Away" picked per game.
- Final button any time (blanks the rest of the innings), Extra inning
  button. Mercy rule: 10+ runs after 4 innings, losing team always
  gets its last chance (app asks, never ends the game on its own).
- Team view = basic MLB Gameday: score, inning, outs, runners, batter
  and on deck, last play, play-by-play, Saucers box score.
- Scorekeepers: the two clipboard keepers share one score-only key that
  can't change the lineup.
- Hosting: trial on GitHub (separate score repo published by a GitHub
  Actions workflow, about a minute behind, since plain Pages allows
  only ~10 rebuilds an hour). Move to a Cloudflare-style live service
  once it's a solid V2.
- Mock-up built and shared (private claude.ai page).

V2 / V3 additions
- Formal name plus a nickname / alternate name for each player, so the
  stats show the right name while the lineup keeps using nicknames.
  (Decided: the published lineup and game log stay as they are for now.)
- Mid-game substitutions: the scorekeeper taps players in and out
  during the game, which gives real innings / playing time. Goes with
  the live score feed.
Ideas

  is public).
- Short nichollshd.github.io link that forwards to the app.
- Field nicknames are guesses (WB 2, SB 7...). Edit them in Manage fields.
